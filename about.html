About The Company

We started this club after one too many group chats died mid-planning.

Core Memories Club began with a simple frustration: every festival trip our friend group dreamed up — Tomorrowland, Ibiza, a spontaneous Iceland run — fell apart somewhere between the group chat and the group booking.

So we built the thing we wished existed — a travel club that handles the visas, the flights, the hotel blocks, and the "wait who's paying for what," so the only decision left is which outfit to pack for the closing party.

1,000+ travellers and 30+ destinations later, we're still doing exactly that — one core memory at a time.
